# 跑步节拍（PaoBu）

围绕「5 公里稳定 23:00」的安卓跑步小工具：跑前设目标距离、配速、每公里计划和步频，跑步中用 GPS 和计步传感器实时显示数据，并按计划语音提醒你修正。

## 功能（最小可用版）

- 跑前设置：距离（3/5/8/10 km 或自定义），平均配速或目标用时，每公里计划（稳起·匀速·末段提速 / 全程匀速 / 负分割），步频
- 跑步中：距离、用时、当前配速（最近约 25 秒）、平均配速、当前/平均步频、领先或落后计划多少秒、本公里目标配速
- 节拍器：按步频打拍，不打断其他音乐 App
- 语音（系统中文 TTS，播报时音乐自动压低）：
  - 每公里：用时、比计划快/慢多少、下一公里目标
  - 偏离计划超过 N 秒时提醒（最多每分钟一次）
  - 可选定时播报当前配速
  - 跑到目标距离自动结束并播报成绩
- 锁屏后台：前台服务 + 通知栏暂停/继续
- 跑完显示每公里分段（不保存历史）

## 安装

每次推送到 `main`，GitHub Actions 会自动打包，并发布到 Releases 里的 **latest**：
`https://github.com/ilcf/PaoBu/releases/tag/latest` → 下载 `PaoBu.apk` 安装。
APK 用固定签名，新版本可以直接覆盖安装。

## 首次使用

1. 允许定位（使用 App 时允许）、身体活动（步频）、通知
2. 在 App 里点「关闭电池优化」，再按「红米 / 一加 具体怎么设？」设置省电策略无限制和自启动
3. 系统“文字转语音”引擎设为中文引擎（App 会提示是否可用）
4. 室外等 GPS 精度 ≤ 20 米再点开始

## 本地构建

需要 JDK 17 和 Android SDK（Android Studio 打开本项目即可），或执行 `gradle assembleDebug`（Gradle 8.11）。
